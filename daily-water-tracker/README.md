# 每日喝水紀錄器

純前端每日飲水紀錄網頁，符合專案規格書要求。

## 使用方式

直接雙擊 `index.html`，或將整個資料夾放在任意靜態網站空間即可使用。

## 功能

- `+250 ml`：增加 250 ml
- `-250 ml`：減少 250 ml，最低不低於 0
- 每日目標固定為 2000 ml
- 即時更新飲水量與進度條
- 超過 2000 ml 時進度條仍維持 100%
- 達標顯示「已達成每日飲水目標」
- 使用 LocalStorage 自動保存資料
- `重置今日紀錄`：將飲水量歸零並同步保存

## 檔案

- `index.html`：網頁結構
- `style.css`：介面樣式
- `script.js`：飲水紀錄、進度計算與 LocalStorage 邏輯

## LocalStorage

資料鍵值：

`dailyWaterAmount`

第一次使用、資料不存在、資料無效或 LocalStorage 無法正常讀取時，飲水量會以 `0 ml` 初始化。
